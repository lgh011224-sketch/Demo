# VR 두더지 게임 (Unity) 설치·실행 안내

모드: 나무 망치 / 쇠 망치 / 사격(번외)
버전: 컨트롤러 버전 / 모듈(아두이노) 버전 — 한 프로젝트에서 체크박스 하나로 전환합니다.
실행 방식: Windows PC에서 Unity를 실행하고, Quest는 Quest Link(케이블 또는 Air Link)로 연결합니다.
(아두이노 시리얼 통신은 PC에서만 동작하므로 Quest 단독 실행 파일은 만들지 않습니다.)

---

## 1. 프로그램 설치 (처음 한 번)

1. **Unity Hub** 설치: https://unity.com/download
2. Unity Hub > Installs > Install Editor > **Unity 6 LTS** 최신 버전 설치
   - 추가 모듈은 선택하지 않아도 됩니다.
3. **Meta Quest Link** PC 앱 설치: https://www.meta.com/help/quest/pcvr
   - 앱 실행 > 설정 > 일반 > **OpenXR 런타임**을 "Meta Quest Link"로 설정

## 2. 프로젝트 만들기

1. Unity Hub > New project > 템플릿 **VR** 선택 > 프로젝트 이름 입력 > Create
   - 처음 열 때 몇 분 걸립니다. 안내 창이 뜨면 기본값으로 진행합니다.
2. 상단 메뉴 **Edit > Project Settings** 를 열고 아래 3가지를 확인합니다.
   - **XR Plug-in Management** > 모니터 모양(PC) 탭 > **OpenXR** 체크
   - **XR Plug-in Management > OpenXR** > Enabled Interaction Profiles 의 **+** 를 눌러 **Oculus Touch Controller Profile** 추가
   - **Player > Other Settings > Api Compatibility Level** 을 **.NET Framework** 로 변경 (모듈 버전의 아두이노 통신에 필요)

## 3. 게임 파일 넣기

1. 받은 압축 파일을 풀면 `WhackAMole` 폴더가 나옵니다.
2. 이 폴더를 Unity의 **Project 창 > Assets** 에 끌어다 놓습니다.
   - 결과: `Assets/WhackAMole/Scripts`, `Assets/WhackAMole/Editor`
3. 하단 Console 창에 빨간 오류가 없으면 정상입니다.

## 4. 장면 만들기

1. **File > New Scene** > Basic (또는 Empty) > Create
2. Hierarchy 창 빈 곳 우클릭 > **XR > XR Origin (VR)**
3. 상단 메뉴 **Tools > Whack-A-Mole > Build Scene** 클릭
   - 탁자, 두더지 9마리, 사격 표적 벽, 나무 망치·쇠 망치·총, 게임 매니저가 자동으로 생깁니다.
   - 기본 Main Camera와 XR Origin의 기본 컨트롤러 모델은 자동으로 꺼집니다.
4. **File > Save** 로 장면 저장 (이름 예: WhackAMole)

## 5. 실행

1. Quest를 PC에 연결하고 Quest 안에서 **Quest Link** 를 켭니다.
2. Unity 상단의 **▶ (Play)** 버튼을 누르면 헤드셋에 게임이 보입니다.
3. 오른손 컨트롤러가 도구가 됩니다.

### 조작

| 동작 | 컨트롤러 | 키보드 (실험자) |
|---|---|---|
| 게임 시작 / 중지 | A 버튼 | Space |
| 모드 바꾸기 (게임 중이 아닐 때) | B 버튼 | 1 나무 망치 / 2 쇠 망치 / 3 사격 |
| 총 발사 (사격 모드) | 트리거 | F |
| HIT 흉내 (아두이노 없이 시험) | — | H |

- 한 판은 기본 60초입니다. 끝나면 맞힘(Hit)·빗맞음(Miss)·정확도가 화면에 표시됩니다.
- 키보드 입력은 Unity 창(Game 탭)을 한 번 클릭해 두어야 받습니다.

## 6. 버전별 판정 방식

**컨트롤러 버전** (GameManager의 Use Module 체크 해제)
- 망치 머리가 올라온 두더지에 아래 방향으로 빠르게 닿으면 맞힘입니다.
- 두더지 없이 탁자만 치면 빗맞음입니다.
- 맞히면 컨트롤러가 짧게 진동합니다.

**모듈 버전** (GameManager의 Use Module 체크)
- 아두이노가 `HIT` 를 보낸 순간, 망치 머리 바로 아래(반경 안)에 올라온 두더지가 있으면 맞힘, 없으면 빗맞음입니다.
- 사격 모드에서는 아두이노가 `BTN` 을 보내면 발사합니다. (컨트롤러 트리거도 그대로 동작)
- 모드를 바꿀 때 해당 모드의 모듈 형태 변경 명령을 아두이노로 보냅니다.

## 7. 모듈 버전 설정

Hierarchy > WhackAMole > **Arduino** 선택 > Inspector:
- **Port Name**: 장치 관리자 > 포트(COM & LPT)에 보이는 아두이노 포트 (예: COM5)
- **Baud Rate**: 아두이노 코드 `Serial.begin(...)` 의 값

Hierarchy > WhackAMole > **GameManager** 선택 > Inspector:
- **Use Module**: 체크
- **Hit Message / Button Message**: 아두이노가 `Serial.println()` 으로 보내는 글자와 똑같이 입력 (기본 `HIT`, `BTN`)
- **Wood Command / Hammer Command / Gun Command**: 각 모드에서 모듈 형태를 바꾸는 명령. 여러 개는 `;` 로 구분 (예: `m3 on;s 90`)
- **Hit Feedback Command**: 두더지를 맞혔을 때 보낼 명령 (예: 진동). 비워 두면 보내지 않습니다.

주의
- 아두이노 IDE의 **시리얼 모니터를 닫아야** Unity가 포트를 열 수 있습니다.
- 포트를 열면 아두이노가 재시작되므로, 첫 모드 명령은 약 2.5초 뒤에 다시 보냅니다.
- 주고받은 메시지는 Unity Console 창에 `[Arduino →]`, `[→ Arduino]` 로 표시됩니다.

## 8. 도구 위치·방향 맞추기

컨트롤러에 따라 망치 손잡이 방향이 손과 어긋나 보일 수 있습니다.
- Hierarchy > XR Origin > Camera Offset > **ToolRoot** 선택
- **Position Offset / Rotation Offset** 값을 바꿉니다. (Play 중에 바꾸면 바로 보이지만, Play를 끄면 원래 값으로 돌아가므로 맞는 값을 적어 두었다가 다시 입력)
- 모듈 버전처럼 컨트롤러를 헤드가 아래로 향하게 꽂으면 Rotation Offset의 X를 180 근처로 조정합니다.

## 9. 게임 조절 (GameManager)

| 항목 | 뜻 | 기본값 |
|---|---|---|
| Round Seconds | 한 판 시간 (초) | 60 |
| Spawn Interval Min / Max | 두더지 등장 간격 (초) | 0.6 / 1.2 |
| Mole Stay Time | 두더지가 올라와 머무는 시간 (초) | 1.0 |
| Max Moles Up | 동시에 올라오는 최대 두더지 수 | 2 |

망치별 판정 범위는 WoodTool / HammerTool 아래 **HitPoint** 의 Hit Radius(모듈 버전)와 Min Swing Speed(컨트롤러 버전)에서 바꿉니다.

## 10. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 헤드셋에 화면이 안 나옴 | Quest Link가 켜져 있는지, Meta Quest Link 앱의 OpenXR 런타임 설정 |
| 도구가 손을 따라오지 않음 | Project Settings > OpenXR > Interaction Profiles에 Oculus Touch Controller Profile 추가 여부 |
| Console에 `System.IO.Ports` 오류 | Api Compatibility Level을 .NET Framework로 변경 |
| `[Arduino] 연결 실패` | 포트 이름, 시리얼 모니터 닫힘 여부, USB 케이블 |
| 망치로 쳐도 반응 없음 (컨트롤러 버전) | HitPoint의 Min Swing Speed를 낮춤 (예: 0.6 → 0.3) |
| 모듈 버전에서 계속 빗맞음 | HitPoint의 Hit Radius를 키움, ToolRoot 오프셋으로 망치 머리 위치를 실제 모듈 끝에 맞춤 |
| 글자가 깨짐 | 화면 표시는 영어로만 되어 있으므로 정상이라면 깨지지 않습니다 |

## 8. 아두이노 진동 출력 (두더지 잡기 · 사격장 공통)

컨트롤러가 진동할 때마다 **같은 세기·시간을 아두이노로도 한 줄 보냅니다.** (컨트롤러 버전·모듈 버전 모두)
- 담당 스크립트: `ArduinoHaptics` (각 씬의 **Arduino** 오브젝트) – `Send To Arduino` 체크로 켜고 끔
- 포트·속도: 같은 오브젝트의 `ArduinoSerial` (기본 COM3, 9600bps) – 두 씬 각각 맞춰 주세요
- 형식: `VIB <세기 0~255> <시간 ms>` + 줄바꿈

| 상황 | 보내는 값 |
|---|---|
| 귀여운 두더지 맞힘 | `VIB 128 80` |
| 초록 두더지 맞힘 | `VIB 255 80` |
| 틀린 도구로 침 | `VIB 38 200` |
| 도구 전환 | `VIB 89 40` |
| 카운트다운 3·2·1 / START! | `VIB 64 50` / `VIB 178 150` |
| 권총 발사 | `VIB 255 70` |
| 빈 격발 (표적 준비 전) | `VIB 26 30` |
| 표적 출발 / 도착 | `VIB 76 50` / `VIB 51 40` |

세기는 `GameManager`(두더지)와 `RangeManager`(사격장) 인스펙터의 진동 항목에서 바꿀 수 있습니다.

**아두이노 없이 확인하기**: Play 하면 Console 창에 `[→ Arduino (미연결·확인용)] VIB 128 80` 처럼 보냈을 명령이 찍히고,
Arduino 오브젝트의 `ArduinoSerial > Recent Sent` 목록에도 최근 30개가 남습니다.

**아두이노 쪽 예제 코드**: 프로젝트 폴더 `Arduino/HapticReceiver/HapticReceiver.ino`
(VIB 명령을 받아 PWM 핀으로 진동 모터를 돌리고, 확인용으로 `OK VIB ...` 를 돌려보냄 → Unity Console에 `[Arduino →]` 로 표시)
